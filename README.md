**1st International Workshop on XR for Behavioral Health: Body Signals, Behavior Change, and Responsible Design**

ISMAR 2026 · October 6, 2026 · Bari, Italy · Hybrid

## Hosting on GitHub Pages

1. Create a new repository (e.g. `behavxr26`) under your GitHub account or team account
2. Upload all files in this folder to the repository root
3. Go to **Settings → Pages → Source** and select `main` branch, `/ (root)` folder
4. Your site will be live at `https://[your-org].github.io/behavxr26/`

## File structure

```
index.html        ← Home page
cfp.html          ← Call for Papers
organizers.html   ← Organizers & Program Committee
style.css         ← Shared styles
README.md         ← This file
```

## Updating dates

Search for `TBC` across all HTML files and replace with the confirmed dates when available.
